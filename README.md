# memome
個人用メモアプリ
始める前、終わった後に必ず同期をすること。同期ではなく上書きに近い。

使い方
windows,macOS,iOSで動作確認済み。
githubプライベートリポジトリを利用したマルチプラットフォームで同期可能なメモアプリです。
memomeはWPAのアプリです。デスクトップやホーム画面に追加し、オフラインで使用できます。

1,　プライベートリポジトリを作成
2,　Personal Access Token を作成 repo権限を含めてください。
3,　memomeアプリ内、画面左下の設定からリポジトリとPATを入力し保存。
4,　右上の更新マークを押し、更新が成功したら正常に機能します。

5,　＋ボタンで新しいメモ。
6,　メモ内の機能は、左から順に
　　見出し化、文字サイズ変更(4段階)、区切り線、装飾消し、画像挿入、エクスポート、メモ削除
  　です。
   見出し化：選択した行を見出しにします。同じレベルの見出し または 区切り線 までを折りたたむことができます。
   装飾消し：選択部分の文字に含まれた強調、記号、装飾などを消去し、シンプルな文章のみにできます。
   エクスポート：md形式でダウンロードします。かなり雑な変換なので見出しなどのタグはHTMLのものが残ります。
   メモ削除：複数端末で利用する場合は、全ての端末で削除→同期の作業をしてください。
